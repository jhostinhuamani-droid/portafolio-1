## Secciones
Inicio · Nosotros (Acerca de mí, habilidades y profesores) · Galería · Testimonios · Contacto

## Proyectos de la galería
- **Café Andino** – página web de una cafetería (HTML5 y CSS3).
- **GameZone** – tienda de videojuegos con carrito (HTML5, CSS3 y JavaScript).

## Características
- Diseño adaptable a celular, tablet y computadora.
- Menú hamburguesa en pantallas pequeñas.
- Formulario de contacto que guarda los mensajes en MySQL (`envio.php`).
- Enlaces de contacto: correo, LinkedIn y WhatsApp.

## Estructura
```
index.html      Página principal
envio.php       Procesa el formulario y guarda en MySQL
database.sql    Crea la tabla "formulario"
css/ js/ img/   Estilos, scripts e imágenes
proyectos/      Café Andino y GameZone
```

## Cómo configurarlo
1. Crea una base de datos MySQL y ejecuta `database.sql`.
2. En `envio.php` escribe tu servidor, usuario, contraseña y nombre de la base de datos.
3. Sube todo a la carpeta pública del hosting (`htdocs` en InfinityFree).

> Por seguridad, la contraseña real de la base de datos no está en este repositorio.
